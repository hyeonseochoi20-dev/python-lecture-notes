HTML이란?

HTML(HyperText Markup Language)은 웹 페이지의 구조를 정의하는 마크업 언어입니다.

  • 태그(tag)로 구성 요소들을 정의합니다
  • 웹 브라우저가 해석해서 화면에 표시합니다
  • 구조만 담당하며, 스타일은 CSS가 담당합니다

기본 HTML 구조

<!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="utf-8">
    <title>페이지 제목</title>
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
</head>
<body>
    <!-- 화면에 표시되는 내용 -->
    <h1>메인 제목</h1>
    <p>단락 텍스트</p>
    <!-- ... -->
</body>
</html>

DOCTYPE 선언

<!DOCTYPE html>는 HTML5임을 선언합니다. 이 선언이 없으면 브라우저가 쿼크 모드(quirks mode)로 렌더링할 수 있습니다.

head 요소

브라우저에 대한 메타데이터를 제공합니다 (화면에 표시되지 않음):

  • <meta charset="utf-8">: 문자 인코딩 지정 (한글 정상 표시 필수)
  • <title>: 브라우저 탭 제목 및 북마크 이름
  • <meta name="viewport">: 모바일 반응형 디자인 필수
  • <link rel="stylesheet">: 외부 CSS 파일 연결
  • <script>: 자바스크립트 코드 또는 외부 파일 연결

body 요소

실제로 화면에 표시되는 내용이 들어갑니다.

CSS(Cascading Style Sheets)란?

HTML 요소에 스타일을 적용하는 언어입니다. HTML은 구조, CSS는 presentación(표현)을 담당합니다.

CSS는 캐스케이딩(cascading) 원리에 따라 여러 스타일 규칙이 충돌할 때 우선순위를 결정합니다.

CSS 적용 방법

1. 인라인 스타일 (Inline Style)

<p style="color: red; font-size: 16px;">빨간 텍스트</p>

단점: 재사용 불가능, HTML과 스타일이 혼합됨

2. 내부 스타일 시트 (Internal Style Sheet)

<style>
    p {
        color: blue;
        font-size: 14px;
    }
</style>

단점: 해당 HTML 문서에서만 사용 가능

3. 외부 스타일 시트 (External Style Sheet) - 권장 방법

<!-- HTML 파일 내 -->
<link rel="stylesheet" href="styles.css">

/* styles.css 파일 내용 */
p {
    color: green;
    font-size: 18px;
}

장점: 재사용 가능, 캐싱으로 인한 성능 향상, 유지보수 용이

CSS 선택자(Selector) 완전 정리

CSS 선택자는 크롤링에서 select()/select_one()을 쓸 때도 그대로 사용되므로 정확히 익혀두면 크롤링 실력이 크게 향상됩니다.

선택자 종류문법예시
전체** { }
태그태그명li { }
클래스.클래스명.product { }
아이디#아이디명#gnb { }
속성[속성=값][data-stock="out"] { }
인접 형제A + B.highlight + tr { }
일반 형제A ~ B.special ~ li { }
자식A > B.wrapper > main { }
하위(자손)A B.wrapper li { }
n번째 자식:nth-child(n)tr:nth-child(2) { }
n번째 같은타입:nth-of-type(n)td:nth-of-type(2) { }

  • border: 2px solid red: 테두리
  • font-size: 20px: 글자 크기

/* 9. data-stock="out" 속성을 가진 행 */

/* 11. highlight 다음 바로 오는 형제 행 */
