📦 변수 완전 정리

변수 정의

변수는 값을 저장할 수 있는 메모리 공간입니다.

  • 재사용 가능
  • 값에 이름을 붙여서 사용하기 쉬움
  • 반복 등장하는 값을 관리하기 좋음

변수명 규칙

규칙예시가능여부
글자, 숫자, 언더바(_)만user_name가능
숫자로 시작 금지user1 vs 1user좋음 / 안됨
빈칸 안됨user_name vs user name좋음 / 안됨
대소문자 구분UserName vs username다름

네이밍 컨벤션

# snake_case (파이썬 공식)
user_name = "홍길동"
total_score = 100

# camelCase
userName = "홍길동"
totalScore = 100

# PascalCase
UserName = "홍길동"
TotalScore = 100

변수 할당 방법

# 숫자
var1 = 12345

# 문자열
var2 = 'Python'

# 리스트
var3 = ['a', 'b', 'c', 'd', 'e']

# 딕셔너리
data = {'a': 1, 'b': 2, 'c': 3}

# 튜플로 동시 할당
a, b = ('python', 'variable')  # a='python', b='variable'

# 리스트로 동시 할당
a, b = ['python', 'variable']  # 동일하게 동작

# 같은 값 여러 변수
x = y = 1234  # x=1234, y=1234

# 값 교환 (파이썬 특유)
a, b = b, a

타입 힌트 (Type Hinting)

var1: str = 'Python'      # 문자열
var2: int = 12345       # 정수
var3: list[str] = ['a']  # 문자열 리스트
data: dict[str, int] = {'a': 1}  # 문자열-정수 매핑

def greet(name: str) -> str:
    return f"Hello {name}"

문자열 연산

s = "hello"

# 인덱싱 (0부터 시작)
print(s[0])   # h
print(s[-1])  # o

# 슬라이싱
print(s[1:4]) # ell
print(s[:3])  # hel
print(s[2:])  # llo

# 연결
s2 = s + " world"  # hello world

# 반복
s3 = "hi" * 3  # hihihi

# 길이
print(len(s))   # 5

연습문제

초를 시:분:초로 변환 
sec = 3703

hour = sec // 3600
minute = (sec % 3600) // 60
second = sec % 60

print(f"{hour}시간 {minute}분 {second}초")  # 1시간 1분 43초
