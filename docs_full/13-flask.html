🌶️ Flask 완전 정리

💡 학습 목표: Flask로 웹 서버를 직접 만들어보고, 지금까지 배운 requests/크롤링과 반대 방향(서버 쪽)의 관점을 이해하기

Flask란?

Flask는 파이썬으로 웹 서버를 만들 수 있게 해주는 가벼운 웹 프레임워크입니다. 지금까지는 requests로 "다른 서버에 요청을 보내는 클라이언트" 입장이었다면, Flask는 반대로 "요청을 받아서 응답을 돌려주는 서버" 입장의 코드를 작성하게 됩니다.

💡 클라이언트와 서버, 두 관점을 모두 갖는다는 것
크롤링(requests)을 배울 때는 "이미 존재하는 남의 서버"에 요청을 보내는 역할이었습니다. Flask를 배우면 이번엔 내가 직접 서버가 되어 브라우저나 다른 프로그램의 요청을 받고 응답을 만들어 돌려주는 쪽을 경험하게 됩니다. 두 관점을 모두 경험하면 웹 통신의 전체 그림이 훨씬 명확해집니다.

from flask import Flask

app = Flask(__name__)

@app.route('/')
def home():

이 파일을 실행하면 http://127.0.0.1:5000에서 서버가 켜지고, 브라우저로 접속하면 "Hello, Flask!"가 화면에 표시됩니다.

라우팅(Routing) - 주소별로 다른 함수 연결하기

from flask import Flask

app = Flask(__name__)

@app.route('/')
def home():
    return '메인 페이지'

@app.route('/about')
def about():
    return '소개 페이지'

# URL 안에 변수를 담아 전달받기
@app.route('/user/<name>')
def user_page(name):
    return f'{name}님의 페이지입니다'

# 타입 지정도 가능
@app.route('/item/<int:item_id>')
def item_page(item_id):
    return f'{item_id}번 상품 (타입: {type(item_id)})'

핵심 포인트: <name>처럼 꺾쇠괄호로 감싼 부분은 URL의 그 위치에 들어온 실제 값을 함수의 매개변수로 그대로 전달받습니다. 예를 들어 /user/kim으로 접속하면 name에 'kim'이 담겨 함수가 실행됩니다.

GET과 POST 요청 처리하기

앞서 크롤링 챕터에서 배운 CRUD-HTTP 매핑이 여기서도 그대로 적용됩니다. 하나의 라우트가 GET과 POST를 모두 처리하게 하려면 methods 옵션을 지정합니다.

from flask import Flask, request

app = Flask(__name__)

@app.route('/search')
def search():
    # GET 방식: URL의 ?키워드=값 부분을 request.args로 받음
    keyword = request.args.get('keyword', '')
    return f'검색어: {keyword}'
    # 접속 예: /search?keyword=파이썬

@app.route('/login', methods=['GET', 'POST'])
def login():
    if request.method == 'POST':
        # POST 방식: HTML 폼으로 전송된 데이터는 request.form으로 받음
        user_id = request.form.get('id')
        password = request.form.get('password')
        return f'{user_id}님, 로그인 시도됨'
    else:
        # GET으로 접속했을 때는 로그인 폼을 보여줌
        return '''
            <form method="POST">
                아이디: <input type="text" name="id"><br>
                비밀번호: <input type="password" name="password"><br>
                <input type="submit" value="로그인">
            </form>
        '''

@app.route('/api/data', methods=['POST'])
def api_data():
    # JSON으로 전송된 데이터는 request.json으로 받음
    data = request.json
    return {'received': data, 'status': 'ok'}
요청 데이터 위치Flask에서 읽는 방법
URL 쿼리스트링 (?key=value)request.args.get('key')
HTML 폼 데이터 (POST Body)request.form.get('key')
JSON 데이터 (POST Body)request.json

템플릿(Template) - HTML을 파이썬 데이터와 결합하기

지금까지는 파이썬 코드 안에 HTML 문자열을 직접 썼지만, 실제로는 HTML을 별도 파일(템플릿)로 분리하고 파이썬에서 데이터만 넘겨주는 방식을 사용합니다. Flask는 기본적으로 Jinja2 템플릿 엔진을 사용합니다.

프로젝트 구조

my_flask_app/
├── app.py
├── templates/          # HTML 템플릿은 반드시 이 폴더 안에
│   └── index.html
└── static/             # CSS, JS, 이미지 등 정적 파일
    └── style.css

app.py

from flask import Flask, render_template

app = Flask(__name__)

@app.route('/')
def home():
    users = ['홍길동', '김철수', '이영희']
    return render_template('index.html', title='회원 목록', users=users)

if __name__ == '__main__':
    app.run(debug=True)

templates/index.html

<!DOCTYPE html>
<html>
<head><title>{{ title }}</title></head>
<body>
    <h1>{{ title }}</h1>
    <ul>
    {% for user in users %}
        <li>{{ user }}</li>
    {% endfor %}
    </ul>
</body>
</html>

핵심 포인트: {{ 변수명 }}은 파이썬에서 넘겨준 값을 그 자리에 출력하고, {% for %} 같은 {% %} 구문은 반복문/조건문 등 로직을 HTML 안에서 사용할 수 있게 해줍니다. render_template()의 키워드 인자로 넘긴 이름이 곧 템플릿 안에서 쓸 수 있는 변수명이 됩니다.

실전 예제: 미니 CRUD 게시판 (메모리 저장)

아직 데이터베이스를 연결하지 않고, 파이썬 리스트로 데이터를 임시 저장하는 간단한 CRUD 예제입니다. CRUD 각 동작이 어떤 HTTP 메소드와 라우트에 대응하는지 확인해보세요.

from flask import Flask, request, jsonify

app = Flask(__name__)

# 메모리에 임시 저장 (서버를 재시작하면 사라짐)
posts = [
    {'id': 1, 'title': '첫 번째 글', 'content': '안녕하세요'},
]
next_id = 2

@app.route('/posts', methods=['GET'])
def get_posts():
    """R: 전체 게시글 목록 조회"""
    return jsonify(posts)

@app.route('/posts/<int:post_id>', methods=['GET'])
def get_post(post_id):
    """R: 게시글 1개 상세 조회"""
    post = next((p for p in posts if p['id'] == post_id), None)
    if post is None:
        return jsonify({'error': '게시글을 찾을 수 없습니다'}), 404
    return jsonify(post)

@app.route('/posts', methods=['POST'])
def create_post():
    """C: 게시글 생성"""
    global next_id
    data = request.json
    new_post = {'id': next_id, 'title': data['title'], 'content': data['content']}
    posts.append(new_post)
    next_id += 1
    return jsonify(new_post), 201

@app.route('/posts/<int:post_id>', methods=['PUT'])
def update_post(post_id):
    """U: 게시글 수정"""
    post = next((p for p in posts if p['id'] == post_id), None)
    if post is None:
        return jsonify({'error': '게시글을 찾을 수 없습니다'}), 404
    data = request.json
    post['title'] = data.get('title', post['title'])
    post['content'] = data.get('content', post['content'])
    return jsonify(post)

@app.route('/posts/<int:post_id>', methods=['DELETE'])
def delete_post(post_id):
    """D: 게시글 삭제"""
    global posts
    posts = [p for p in posts if p['id'] != post_id]
    return jsonify({'result': '삭제 완료'})

if __name__ == '__main__':
    app.run(debug=True)

정리: GET /posts(목록 조회), GET /posts/1(상세 조회), POST /posts(생성), PUT /posts/1(수정), DELETE /posts/1(삭제) — 앞서 배운 CRUD-HTTP 대응 관계가 실제 라우트 설계에 그대로 적용된 모습입니다. 이후 데이터베이스 챕터에서 배운 SQL을 posts 리스트 대신 실제 테이블 조작으로 바꾸면, 이것이 곧 실전 웹 서비스의 기본 골격이 됩니다.

문제: 방문자 수 카운터 만들기

서버가 켜져 있는 동안, 홈페이지에 접속할 때마다 방문 횟수가 1씩 증가하여 화면에 표시되는 앱을 만드세요.

from flask import Flask

app = Flask(__name__)
visit_count = 0

@app.route('/')
def home():
    global visit_count
    visit_count += 1
    return f'현재까지 방문자 수: {visit_count}명'

if __name__ == '__main__':
    app.run(debug=True)

🎯 변형문제 - 좋아요(Like) 버튼 카운터 API

게시글의 "좋아요" 개수를 관리하는 간단한 API를 만들어보세요. GET /likes로 현재 좋아요 개수를 조회하고, POST /likes로 요청이 올 때마다 좋아요 개수를 1 증가시켜 반환합니다.

정답 보기 
from flask import Flask, jsonify

app = Flask(__name__)
like_count = 0

@app.route('/likes', methods=['GET'])
def get_likes():
    return jsonify({'likes': like_count})

@app.route('/likes', methods=['POST'])
def add_like():
    global like_count
    like_count += 1
    return jsonify({'likes': like_count, 'message': '좋아요가 추가되었습니다'})

if __name__ == '__main__':
    app.run(debug=True)
