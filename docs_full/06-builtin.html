🔧 내장함수 완전 정리

내장함수란?

파이썬에 기본적으로 포함되어 있는 함수들로, import 없이 바로 사용할 수 있습니다.

내장함수 목록 확인: dir(__builtins__)

수학/계산 관련 함수

함수설명예시결과
abs(x)절댓값abs(-7)7
divmod(a, b)몫과 나머지를 튜플로 반환divmod(17, 5)(3, 2)
max(iterable)최댓값max([90, 80, 70])90
min(iterable)최솟값min([90, 80, 70])70
pow(x, y)x의 y제곱pow(2, 3)8
round(x, n)소수점 n자리까지 반올림round(3.14159, 2)3.14
sum(iterable)합계sum([90, 80, 70])240

실전 예제

scores = [90, 80, 70, 95, 85]
print(f"최고점: {max(scores)}")  # 95
print(f"최저점: {min(scores)}")  # 70
print(f"총점: {sum(scores)}")    # 420
print(f"평균: {sum(scores)/len(scores):.1f}")  # 84.0

# divmod 예제
minutes, seconds = divmod(125, 60)
print(f"{minutes}분 {seconds}초")  # 2분 5초

형 변환 관련 함수

함수설명예시
int(x)정수로 변환int('123') → 123
float(x)실수로 변환float('3.14') → 3.14
str(x)문자열로 변환str(123) → '123'
list(x)리스트로 변환list('abc') → ['a','b','c']
tuple(x)튜플로 변환tuple([1,2,3]) → (1,2,3)
set(x)집합으로 변환set([1,1,2,3]) → {1,2,3}

실전 예제

# 문자열 → 숫자
age_str = "25"
age_int = int(age_str)  # 25

# 숫자 → 문자열
price = 1000
price_str = str(price) + "원"  # "1000원"

# 리스트 → 튜플
numbers_list = [1, 2, 3]
numbers_tuple = tuple(numbers_list)  # (1, 2, 3)

# 숫자열 → 정수 (16진수)
hex_value = "0xFF"
decimal_value = int(hex_value, 16)  # 255

순서/반복 관련 함수

함수설명
range(start, stop, step)범위 객체 생성
enumerate(iterable)(인덱스, 값) 쌍 반환
zip(*iterables)여러 시퀀스를 튜플로 묶음
sorted(iterable)정렬된 리스트 반환
reversed(iterable)역순 반복자 반환

실전 예제

# range
for i in range(1, 6):
    print(i, end=' ')  # 1 2 3 4 5

# enumerate
fruits = ['사과', '바나나', '오렌지']
for idx, fruit in enumerate(fruits, 1):
    print(f'{idx}: {fruit}')  # 1: 사과, 2: 바나나, 3: 오렌지

# zip
names = ['홍', '김', '이']
scores = [90, 85, 95]
for name, score in zip(names, scores):
    print(f'{name}: {score}')

# sorted
numbers = [3, 1, 4, 1, 5]
print(sorted(numbers))  # [1, 1, 3, 4, 5]
print(sorted(numbers, reverse=True))  # [5, 4, 3, 1, 1]

# reversed
for num in reversed(range(1, 4)):
    print(num, end=' ')  # 3 2 1

연습문제

거리 계산 함수 
def distance(start, end):
    """두 점 사이의 거리 계산"""
    dx = abs(end[0] - start[0])
    dy = abs(end[1] - start[1])
    return dx, dy

start = (1, 1)
end = (5, 3)
dx, dy = distance(start, end)
print(f'x 차이: {dx}, y 차이: {dy}')  # x 차이: 4, y 차이: 2
몫과 나머지 구하기 (divmod 활용) 
a = 123
b = 16
quotient, remainder = divmod(a, b)
print(f'{a} ÷ {b} = {quotient}...{remainder}')  # 123 ÷ 16 = 7...11
