📦 외장함수 완전 정리

외장함수란?

파이썬에서 제공하는 표준 라이브러리(표준모듈)로, 사용하기 전에 import를 해야 합니다.

내장함수 vs 외장함수:

구분내장함수외장함수
정의파이썬 내부에 기본 탑재된 함수파이썬에서 제공하는 표준모듈
사용import 불필요import 반드시 필요
예시len(), sum(), max()os, sys, json, random
제공범위자료형 처리, 기본연산파일/네트워크/시간/데이터 처리등

암호화 관련 모듈

hashlib 모듈 (해시)

💡 해시(Hash)란?
임의의 길이를 가진 데이터를 고정된 길이의 (거의) 고유한 값으로 변경하는 것을 말합니다. 이렇게 만들어진 값을 해시값(Hash Code), 이를 생성해주는 함수를 해시 함수(Hash Function)라고 부릅니다.

예를 들어 SHA-256 해시는 2의 256승 가지의 경우의 수를 가지는데, 전 세계 80억 인구가 1초에 하나씩 시도해도 136해(垓) 년이 걸릴 정도의 확률이라 중복(충돌)될 확률은 사실상 0%입니다. 그래서 비밀번호는 원본을 저장하지 않고 해시값만 저장합니다. 
import hashlib

old_pwd = '1234'
m = hashlib.sha256()
m.update(old_pwd.encode())
new_pwd = m.hexdigest()
# 한 줄로: new_pwd = hashlib.sha256(old_pwd.encode()).hexdigest()

print(new_pwd)
# fcbcf165908dd4e97c780f8c7bb...

# 같은 입력이면 항상 같은 해시값 -> 로그인 시 비밀번호를 다시 해시해서 비교
print(hashlib.sha256('1234'.encode()).hexdigest() == new_pwd)  # True

핵심 포인트: 해시는 "되돌릴 수 없는(일방향) 암호화"입니다. 해시값만 보고 원본 비밀번호를 복원할 수 없기 때문에, 서버가 해킹당해도 실제 비밀번호는 안전하게 보호됩니다. 로그인 시에는 사용자가 입력한 비밀번호를 다시 해시해서, DB에 저장된 해시값과 비교만 합니다.

이메일 자동 발송 (smtplib)

서버 모니터링, 알림 자동화 등에 자주 쓰이는 Gmail을 통한 이메일 발송 방법입니다.

💡 사전 준비: 구글 이메일 앱 비밀번호 발급
  1. 구글 gmail.com 계정 준비
  2. [Google 계정 관리] → [보안 및 로그인] → [2단계 인증] 사용 설정 (패스키/전화번호 등 인증 수단 추가)
  3. Google 계정 검색에서 "앱 비밀번호" 검색 (또는 myaccount.google.com/apppasswords 접속)
  4. "앱 이름" 입력 후 16자리 비밀번호 발급 → 일반 로그인 비밀번호 대신 이 앱 비밀번호를 코드에 사용
import smtplib
from email.mime.text import MIMEText
from email.mime.multipart import MIMEMultipart

SMTP_SERVER = "smtp.gmail.com"
SMTP_PORT = 587
SENDER = "my_account@gmail.com"
PASSWORD = "앱비밀번호16자리"   # 일반 로그인 비밀번호 아님! 앱 비밀번호 사용
RECIPIENT = "target@example.com"

def send_email(subject, body):
    msg = MIMEMultipart()
    msg["From"] = SENDER
    msg["To"] = RECIPIENT
    msg["Subject"] = subject
    msg.attach(MIMEText(body, "html"))
    try:
        with smtplib.SMTP(SMTP_SERVER, SMTP_PORT) as server:
            server.starttls()             # TLS 암호화 연결
            server.login(SENDER, PASSWORD)
            server.send_message(msg)
    except Exception as e:
        print(f"❌ 발송 실패: {e}")

send_email("[경고] 디스크 사용량 초과", "<h3>⚠ 디스크 경고</h3><p>서버 점검이 필요합니다.</p>")
print("이메일 발송 완료")

실전 예제: 디스크 사용량 자동 점검 & 이메일 알림

import shutil

def check_disk_usage(path="/", threshold=80):
    total, used, free = shutil.disk_usage(path)
    usage = used / total * 100
    return usage, threshold

if __name__ == "__main__":
    usage, threshold = check_disk_usage("/")
    if usage >= threshold:
        subject = f"[경고] 디스크 사용량 {usage:.1f}% 초과"
        body = f"<h3>⚠ 디스크 경고</h3><p>현재 디스크 사용량은 <b>{usage:.1f}%</b>입니다.<br>서버 점검이 필요합니다.</p>"
        send_email(subject, body)
        print("⚠ 이메일 발송 완료")
    else:
        print(f"정상 (사용량 {usage:.1f}%)")

활용 아이디어: 이 패턴(상태 체크 함수 + 조건부 이메일 발송 함수)은 API 서버 헬스체크, 정기 리포트 발송 등 다양한 모니터링 자동화에 그대로 재사용할 수 있습니다. 예를 들어 여러 API 서버에 각각 requests.get(url)을 보내서 status_code가 200이 아닌 서버가 하나라도 있으면 담당자에게 메일을 보내고, 모두 정상이면 콘솔에만 메시지를 출력하는 식으로 확장할 수 있습니다.

문제 1: 회식비 정산하기 (divmod, round)

총 결제금액을 인원수대로 나눠 1인당 금액과 나머지 금액을 구하고, 100원 단위로 반올림한 금액도 함께 구하세요.

total_price = 187500
people = 7

share, remain = divmod(total_price, people)
print(f'1인당 {share}원, 나머지 {remain}원은 총무가 부담')

rounded = round(total_price / people, -2)
print(f'반올림 정산 시 1인당 {rounded}원')
# 1인당 26785원, 나머지 5원은 총무가 부담
# 반올림 정산 시 1인당 26800.0원

참고: divmod()는 몫과 나머지를 한 번에 구해줍니다. round()의 두 번째 인자로 음수를 주면 정수 자릿수 단위로 반올림할 수 있습니다.

문제 2: 매출 순위표 만들기 (zip, sorted, enumerate)

names = ['김민준', '이서연', '박도윤', '최하은', '정지호']
sales = [3200000, 4550000, 2980000, 4550000, 3870000]

참고: sorted()의 key와 reverse 옵션을 활용하면 딕셔너리나 튜플 리스트도 원하는 기준으로 자유롭게 정렬할 수 있습니다.

문제 3: 회원가입 폼 유효성 검사 (isinstance, all)

def check_signup(user_id, password, age):
    conditions = [
        isinstance(user_id, str),
        len(password) >= 8,
        isinstance(age, int) and age >= 14,
    ]
    return all(conditions)

print(check_signup('minjun01', 'pw12345678', 20))  # True
print(check_signup('minjun01', 'pw123', 20))        # False (비밀번호 짧음)
print(check_signup('minjun01', 'pw12345678', '20')) # False (age가 문자열)

문제 4: 이벤트 쿠폰 코드 만들기 (ord, hex)

user_id = 'minjun01'

codes = [ord(ch) for ch in user_id]
hex_code = hex(sum(codes))[2:]  # 0x 제거

print(f'쿠폰코드: EVENT-{hex_code}')
# 쿠폰코드: EVENT-2f2

참고: ord()는 문자 하나를 정수(유니코드 코드값)로 바꿔주고, hex()의 결과 앞에는 항상 0x가 붙으므로 슬라이싱([2:])으로 제거합니다.

문제 5: 재고 데이터 일괄 처리하기 (map, filter, lambda)

stock_raw = ['120', '35', '8', '250', '64']
stock = list(map(int, stock_raw))

low_stock = list(filter(lambda n: n < 50, stock))
print('재고부족 목록:', low_stock)              # [35, 8]

transfer_list = list(map(lambda n: n // 2 if n >= 100 else n, stock))
print('이관 수량:', [n for n in transfer_list if n != stock[stock.index(n)] or n >= 50])
# 120 -> 60, 250 -> 125로 절반만 이관

문제 7: 경품 이벤트 당첨자 추첨 (random.shuffle, random.sample)

import random

participants = ['user_a','user_b','user_c','user_d','user_e','user_f','user_g','user_h','user_i','user_j']

random.shuffle(participants)  # 리스트 자체를 무작위로 섞음 (반환값 없음)
print('참여자 명단:', participants)

first_prize = random.sample(participants, 1)[0]   # 중복 없이 1명
second_prize = random.sample(participants, 2)      # 중복 없이 2명

import json
import requests

# 가상의 API 응답 시뮬레이션
api_response = '''
{
  "students": [
    {"name": "홍길동", "score": 95},
    {"name": "김철수", "score": 87},
    {"name": "이영희", "score": 92}
  ]
}
'''

# JSON 파싱
data = json.loads(api_response)

# 점수 90점 이상인 학생 필터링
high_scorers = [s for s in data['students'] if s['score'] >= 90]
print("우수 학생:")
for student in high_scorers:
    print(f"  {student['name']}: {student['score']}점")

# 평균 점수 계산
average = sum(s['score'] for s in data['students']) / len(data['students'])
print(f"평균 점수: {average:.1f}점")
