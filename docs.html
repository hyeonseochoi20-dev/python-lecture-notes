가변 인자 (*args, **kwargs)

# 여러 인자 받기
def total(*args):
    return sum(args)

print(total(1, 2, 3, 4, 5))  # 15

# 키워드 인자
def info(**kwargs):
    for key, value in kwargs.items():
        print(f"{key}: {value}")

info(name='홍길동', age=20)

05. 정규표현식 (re)

import re

# 컴파일 (재사용 시 유리)
pattern = re.compile(r'[a-zA-Z]+')

# search: 전체 검색
result = pattern.search('abc123def')
print(result.group())  # abc

# findall: 모두 찾기
results = re.findall(r'\d+', 'a1b22c333')
print(results)  # ['1', '22', '333']

# sub: 치환
text = re.sub(r'\d+', '숫자', 'abc123def456')
print(text)  # abc숫자def숫자

메타문자 완전 정리

기호의미매치 결과활용 예시
.한 문자a.c → abc, a1c[가-힣] 한글
*0개 이상a*b → b, ab, aab\w* 단어 0번 이상
+1개 이상a+b → ab, aab[0-9]+ 숫자 1개 이상
?0~1개colou?r → color, colourhttps? http 또는 https
[]문자셋[abc] → a 또는 b 또는 c[가-힣]+
[^]부정[^0-9] → 숫자 아님[^A-Z] 대문자 아님
^시작^abc → abc로 시작문자열 시작 체크
$끝xyz$ → xyz로 끝문자열 끝 체크
()그룹(a|b)c → ac 또는 bc캡처 그룹
{}횟수a{2,4} → aa, aaa, aaaa정확한 반복 횟수
