🔍 정규표현식 메타문자

기호의미예시
.한 문자 (줄바꿈 제외)a.c → abc, a1c
*0개 이상 (없어도 됨)a*b → b, ab, aab
+1개 이상 (반드시 있어야)a+b → ab, aab
?0~1개colou?r → color, colour
[]문자셋 (or)[abc] → a 또는 b 또는 c
[^]부정 (not)[^0-9] → 숫자가 아닌 것
^시작^abc → abc로 시작
$끝xyz$ → xyz로 끝남

코드 예시

import re
# 메타문자로 한글 추출
pattern = re.compile(r'[가-힣]+')
text = "Hello 안녕하세요"
print(pattern.findall(text))  # ['안녕하세요']

# 이메일 찾기
email = re.findall(r'[a-zA-Z0-9._%+-]+@[a-zA-Z0-9.-]+\.[a-z]+', text)
