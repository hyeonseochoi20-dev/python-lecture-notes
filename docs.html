00. 환경 설정

💡 학습 목표: Python 개발 환경을 올바르게 설정하고, 가상환경을 활용한 프로젝트 관리를 마스터하기

Python 설치 가이드

Windows 설치 절차

  1. 공식 웹사이트 방문: python.org 에서 최신 버전 다운로드
  2. 설치 파일 실행: python-3.xx.x-amd64.exe 파일 실행
  3. 필수 옵션 선택:
    • ☑️ Add Python to PATH (매우 중요!)
    • ☑️ Install launcher for all users
    • ☑️ Add Python to environment variables
  4. 설치 확인:
    # 명령 프롬프트 또는 PowerShell에서 python --version # 예: Python 3.12.0 pip --version # 예: pip 23.3.1 from ... (python 3.12)

macOS/Linux 설치

  • macOS: 기본적으로 Python이 설치되어 있을 수 있으나, brew install python 로 최신 버전 설치 권장
  • Linux: sudo apt update && sudo apt install python3 python3-pip (Ubuntu/Debian 기준)
  • 버전 확인: python3 --version

가상환경 (Virtual Environment) 완전 정복

가상환경이 필요한 이유: 프로젝트별로 독립된 패키지 관리를 통해 버전 충돌을 방지하고, 재현 가능한 환경을 구축하기 위함입니다.

가상환경 생성 및 관리

# 가상환경 생성 python -m venv myproject # 또는 Python 3.3 이상에서 pyvenv myproject # 가상환경 활성화 # Windows: myproject\Scripts\activate # macOS / Linux: source myproject/bin/activate # 활성화 확인 (프롬프트가 (myproject)로 변경됨) (myproject) $ # 패키지 설치 pip install requests flask numpy pandas # 설치된 패키지 확인 pip list pip freeze > requirements.txt # 배포용 파일 생성 # 가상환경 비활성화 deactivate # 가상환경 완전 삭제 (폴더 삭제) rm -rf myproject # 또는 디렉터리 직접 삭제

가상환경 활용 실전 예제

프로젝트 구조 예시

my-python-project/ ├── .venv/ # 가상환경 폴더 (Git에 포함 안 함) ├── src/ # 소스 코드 │ ├── main.py │ └── utils/ ├── tests/ # 테스트 코드 ├── requirements.txt # 필수 패키지 목록 ├── README.md └── .gitignore

실전 워크플로우

  1. 프로젝트 폴더 생성: mkdir myproject && cd myproject
  2. 가상환경 생성: python -m venv .venv
  3. 가상환경 활성화: source .venv/bin/activate (Linux/macOS) 또는 .venv\Scripts\activate (Windows)
  4. 필수 패키지 설치: pip install -r requirements.txt
  5. 개발 진행: python src/main.py
  6. 작업 완료 후: deactivate

01. 기본 자료구조

💡 학습 목표: Python의 기본 자료구조와 연산자를 마스터하여 효율적인 코드 작성 기초 다지기

산술 연산자 완전 정리

연산자의미예시결과활용 예시
+덧셈2 + 35점수 합계 계산
-뺄셈5 - 23잔액 계산
*곱셈3 * 412면적 계산 (가로 * 세로)
/실수 나눗셈7 / 23.5평균 계산
//정수 나눗셈 (몫)7 // 23페이지 수 계산
%나머지 (modulo)7 % 21홀수/짝수 판단
**거듭제곱 (제곱)2 ** 38복리 계산, 이진 트리 높이

복합 대입 연산자

# 기본 변수
counter = 0
total = 100
price = 25000

# 복합 대입 연산자 사용
counter += 1      # counter = counter + 1
total -= 25       # total = total - 25
price *= 1.1      # price = price * 1.1 (10% 인상)
total //= 10      # total = total // 10
price %= 100      # price = price % 100 (마지막 두 자리만 유지)

# 결과 출력
print(f"counter: {counter}, total: {total}, price: {price}")

                
실제 출력: counter: 1, total: 7, price: 750.0
